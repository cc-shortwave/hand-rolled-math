手書きの数学。**NURBS ライブラリも FFT ライブラリも使わない、ブラックボックスなし** —— sin は sin を使うべき場所にだけ。

## 正弦積による素数ふるい — `sieve/`

素数ごとに正弦を 1 つ、すべて掛ける：

$$
F(x) \;=\; \prod_{p \in \{2,\,3,\,5,\,\dots\}} \sin\!\left(\frac{\pi x}{p}\right)
$$

`x` が `p` の倍数のとき、その項はちょうど 0 になる。だからこの積は**合成数**で 0 になり、**素数**では 0 にならない。プログラムはこの曲線を描き、下に使った素数を並べる。

- **179 行**、Python + `pygame`、**数学ライブラリなし**：素数の生成、積、自動スケーリング、スライダの部品まで全部手書き —— `pygame` は窓を開けて線を引くだけ
- 実行：`pip install pygame` のあと `python sieve/埃氏筛连续数学版本.py`
- ブラウザ版：`sieve/web/index.html` を開くだけ —— サーバもビルドも不要、スマホでも動く（ドラッグのつまみはスライダに置き換え）
- 主張はすべて `ファイル:行` まで辿れる：[docs/claims.md](docs/claims.md)

**既知の問題、そのまま残しています。** 積が `1e-14` を下回るとループを抜ける（`sieve/埃氏筛连续数学版本.py:37`）。素数が 20 個くらいを超えると区間の左端でそれが起き、曲線は 0 に貼り付いた直線になる。ブラウザ版は掛け算ではなく `log|F|` を足す —— 同じ関数で、アンダーフローがないだけ。

**これは何で、何ではないか。** この式は新発見ではない。ゼータ関数のオイラー積にある「素数ごとに掛ける」という考えを連続の形で書いたもの。ここでの主張は**自分で導いて実装した**ことであって、**発見した**ことではない。
