# sieve/ — 正弦積による素数ふるい

素数ごとに正弦を 1 つ、すべて掛ける：

$$
F(x) \;=\; \prod_{p \in \{2,\,3,\,5,\,\dots\}} \sin\!\left(\frac{\pi x}{p}\right)
$$

`x` が `p` の倍数のとき、その項はちょうど 0 になる —— つまりリストの中のどれか 1 つの素数で `x` が割り切れれば、積全体が 0 になる。
（厳密には：最初の `k` 個の素数を使い、`x` がその最大より大きく、`k ≥ √x` のとき、「積が 0 でない」＝「`x` は素数」。）
プログラムはこの曲線を描き、下に使った素数を並べる。

## ファイル

- `埃氏筛连续数学版本.py` — 原本、**179 行**、Python + `pygame`、書かれたまま（ファイル名も）保存。**数学ライブラリなし**：素数も積も自動スケーリングもこのファイルの中で計算する —— `pygame` は窓を開けて線を引くだけ
- `web/index.html` + `web/sieve.js` — ブラウザ移植版。HTML を直接開けば動く（サーバー不要、ビルド不要）。スマホでも操作できるよう、ドラッグではなくスライダー

## 起動方法

```bash
pip install pygame

```

ブラウザ版：`web/index.html` を直接開くだけ。

## アイデアの由来

作者がゼータ関数を遊びでいじっていて、「1/2 線（リーマン予想）で素数を予測する」話の中に `sin` が出てくることに気づいた。`sin` は周期関数で、一周期ごとに間隔が空く。ふるいが欲しいのはまさに「一周期ごとに数を消す」仕組みだったので、素数ごとに `sin` を 1 つ置いて全部掛ける形を思いついた。

## これは論理の誤りではなく、精度しきい値の話

積が `1e-14` を下回るとループを抜ける（`埃氏筛连续数学版本.py:37`）。このしきい値は「ここまで小さければ 0 とみなす」という意味（その数は当時作者が**その場で感覚で調整したもので、計算したものではない**）—— 数学的には零点は零点のままなので論理に誤りはない。ただし素数が増えて `x` が区間の左端に寄ると、真値は `1e-71` の桁まで落ち、それがすべて 0 扱いになるため、曲線は 0 に貼り付いた直線になる。ブラウザ版は掛け算ではなく `log|F|` を足す：同じ関数を、その起伏まで描ける形に書き直しただけ。

この式は新発見ではない。ゼータ関数のオイラー積にある「素数ごとに掛ける」という考えを連続の形で書いたもの。
