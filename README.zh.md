## 正弦乘积筛素数 — `sieve/`

每个素数配一个正弦，全部相乘：

$$
F(x) \;=\; \prod_{p \in \{2,\,3,\,5,\,\dots\}} \sin\!\left(\frac{\pi x}{p}\right)
$$

`x` 是 `p` 的整数倍时，那一项正好为零。所以这个乘积在**合数**上归零、在**素数**上不为零。程序把这条曲线画出来，并在下方标出它用到的素数。

- **179 行**，Python + `pygame`，**不用数学库**：素数、乘积、自适应缩放都在这个文件里算出来 —— `pygame` 只负责开窗口和画线
- 跑起来：`pip install pygame` 然后 `python sieve/埃氏筛连续数学版本.py`
- 网页版：直接双击 `sieve/web/index.html` —— 不用起服务、不用构建，手机上也能玩（拖拽手柄换成了滑块）
- 每条宣称都能指到 `文件:行号`：[docs/claims.md](docs/claims.md)

**已知道的问题，原样保留。** 乘积一旦小于 `1e-14` 就提前跳出循环（`sieve/埃氏筛连续数学版本.py:37`）。素数超过 20 个左右，这在区间左端就会发生，曲线于是被压成一条贴着零的直线。网页版改成累加 `log|F|`，是同一个函数，但没有下溢。

**这是什么、不是什么。** 这个式子不是新发现 —— 它是 ζ 函数欧拉乘积里那个"逐素数相乘"的想法，写成连续形式。这里是**独立推导并实现**，口径是「推导与实现」，不是「发现」。
