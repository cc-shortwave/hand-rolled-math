## 正弦乘积筛素数 — `sieve/`

每个素数配一个正弦，全部相乘：

$$
F(x) \;=\; \prod_{p \in \{2,\,3,\,5,\,\dots\}} \sin\!\left(\frac{\pi x}{p}\right)
$$

`x` 是 `p` 的整数倍时，那一项正好为零 —— 所以只要 `x` 被列表里某个素数整除，整个乘积就归零。
（严格地说：取前 `k` 个素数、`x` 比其中最大的那个还大、并且 `k ≥ √x` 时，「乘积不为零」才等价于「`x` 是素数」。）
程序把这条曲线画出来，并在下方标出它用到的素数。

- **179 行**，Python + `pygame`，**不用数学库**：素数、乘积、自适应缩放都在这个文件里算出来 —— `pygame` 只负责开窗口和画线
- 启动方法：`pip install pygame` 然后 `python sieve/埃氏筛连续数学版本.py`
- 网页版运行方法：直接双击 `sieve/web/index.html`

**想法由来**：作者在玩黎曼 ζ 函数、看「用 1/2 线上的零点预测素数」那些说法的时候，注意到里面有个 `sin`。
`sin` 是周期函数，一个周期一个间隔；而筛子要的正好是「每隔一个周期就把数划掉」的办法 —— 于是给每个素数配一个 `sin`，全部相乘。

**这不是逻辑错误，是精度阈值的问题。** 乘积一旦小于 `1e-14` 就提前跳出循环（`sieve/埃氏筛连续数学版本.py:37`）。这条阈值的意思是「小到这个程度就当作零」（这个数是当时作者**随手调的，不是算出来的**）——数学上零点仍然是零点，逻辑没有错；但素数一多、`x` 又靠近区间左端时，真值会小到 `1e-71` 这样的量级，统统被这条阈值当成 0，曲线于是塌成一条贴着零的直线。网页版改成累加 `log|F|`，是同一个函数，换一种能把这段起伏也画出来的写法。

这个式子不是新发现 —— 它是 ζ 函数欧拉乘积里那个"逐素数相乘"的想法，写成连续形式。
